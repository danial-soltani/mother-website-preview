# HOKARI early-launch staging (V9.0)

This branch is intentionally isolated from `main` and RP4. No actual customer inquiry is accepted by the preview form. Product download links remain disabled until verified. English is the default UI language, with Persian supported.

## Brand attribution
Client websites: `Powered by **HOKARI**` and a smaller `Sol & Solly` credit. This is a reusable proposal; HOKARI remains a working name until finalized.

## Launch gates
- Confirm legal brand/domain and privacy notice.
- Publish independently crawlable EN/FA pages, metadata and hreflang.
- Set up a dedicated (non-Pet-Life) database and authenticated private intake.
- Connect verified app links/APK signatures and ownership permissions.
- Check accessibility, mobile zoom/scroll, security, backups, lighthouse.
- Apply user-specified light detail only during Ready.

Staging should remain `noindex` until the launch gates pass.
